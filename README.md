# Online Code Evaluator

An online coding practice and evaluation platform that allows users to write, compile, and execute code in multiple programming languages with real-time output and custom inputs.

## 🚀 Live Demo
[Click Here to Access Live App](https://online-code-evaluator.onrender.com)

---

## 🛠️ Features
- **Multi-language Support:** Execute Python, C++, and Java code.
- **Custom Input Handling:** Test programs with dynamic custom inputs.
- **Instant Output Feedback:** Real-time execution results and compilation error logs.
- **Cloud Deployed:** Hosted on Render with Gunicorn server configuration.

---

## 💻 Tech Stack
- **Backend:** Python, Flask, Gunicorn
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
- **Deployment:** Render Platform
